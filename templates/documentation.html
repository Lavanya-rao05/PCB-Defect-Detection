About the Project

This project focuses on developing an automated defect detection system for Printed Circuit Boards (PCBs) using YOLOv5, a state-of-the-art deep learning model. PCBs are crucial for electronic devices, and defects like missing holes, mouse bites, and spurs can lead to malfunction. Traditional manual inspection is slow and error-prone. Our system uses image processing techniques such as median filtering, thresholding, and high-pass filtering to enhance defect visibility. Features are extracted using Histogram of Oriented Gradients (HOG), followed by defect classification with Convolutional Neural Networks (CNNs). The goal is to ensure real-time, accurate, and cost-effective quality control. The model is trained on a diverse dataset to handle multiple PCB defect types. Testing ensures robust performance under various conditions. This approach improves manufacturing efficiency and product reliability.

Applications of PCB Defect Detection

This system can be integrated into:

  • Automated production lines in PCB manufacturing industries
  • Quality assurance labs for electronics companies
  • Educational and research labs focusing on computer vision and defect detection
  • Small- to mid-scale PCB design units to ensure product quality

Why This Project is Important

Manual PCB inspection is prone to human error, time-consuming, and costly. This project automates the detection of common PCB defects such as:

  • Missing holes
  • Mouse bites
  • Spurs
  • Open circuits or short circuits
Using YOLOv5 and deep learning ensures: Higher accuracy faster processing time, and scalability across different PCB types.
